# Bisi Bele — concept demo

Self-initiated concept demo for a South Indian restaurant site (Kharghar / Navi Mumbai). **Not a live restaurant site.**

Built as a portfolio “Open live” pilot: menu discovery, visit context, and a fake order/enquire success path — no payments, no live kitchen, no studio WhatsApp.

## Stack

- Next.js App Router + TypeScript
- CSS (no heavy UI libs)
- Hero asset: `public/demo-bisi-bele.jpg`

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Concept notes

- Primary CTA: **Explore today’s menu →** → `#menu`
- Order / enquire: client form → fake success “Enquiry received — concept demo”
- Menu prices and hours are labeled concept content
- EN only (Marathi = P1, not this pilot)
- Footer + chip: “Self-initiated concept demo. Not a live restaurant site.”

## Anchors

`#top` · `#menu` · `#story` · `#visit` · `#favourites` · `#order`
